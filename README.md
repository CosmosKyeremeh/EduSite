## 📖 Overview

This project showcases a full landing-page website for a school or online learning platform.  
It includes:

- Hero landing section
- About section
- Teachers profiles
- Courses offered
- Student reviews
- Contact form

The goal was to practice responsive design and basic front-end interactions.
